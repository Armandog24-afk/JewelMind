# Artifact Integrity Model

## The 8 conceptual levels, and what actually runs

| Level | Meaning | Runs for every real request? |
|---|---|---|
| `FILE_EXISTENCE` | The destination path exists after the exporter returns | Yes — `validate_non_empty()` |
| `NON_ZERO_SIZE` | The file is not empty | Yes — same function |
| `EXPECTED_EXTENSION` | The file's actual bytes match the extension claimed in its filename | No |
| `EXPECTED_MIME` | The file's actual bytes match the MIME type sent in the response | No — the MIME type is a fixed literal, never derived from content |
| `CHECKSUM` | A content-addressed digest is computed and available to the caller | Yes — `sha256_checksum()`, exposed via `X-Content-SHA256` |
| `FORMAT_SIGNATURE` | The file's own internal structure matches its format's specification | STL only — `binary_stl_triangle_count()`; not implemented for STEP |
| `PARSER_OR_REIMPORT_VALIDATION` | A real parser/importer can read the file back without error | Test-suite only — `cadquery.importers.importStep()` in `test_export_integrity.py` |
| `GEOMETRIC_ROUNDTRIP_VALIDATION` | The re-imported geometry matches the original within tolerance | Test-suite only — same test, `pytest.approx(rel=1e-3)` |

**Do not claim validation that is not actually executed.** Only `FILE_EXISTENCE`, `NON_ZERO_SIZE`, and `CHECKSUM` are guarantees a real caller of the production API can rely on today. `FORMAT_SIGNATURE` is a real, executed guarantee, but only for STL. `PARSER_OR_REIMPORT_VALIDATION` and `GEOMETRIC_ROUNDTRIP_VALIDATION` prove the exporter *code path* works, re-verified on every CI run — they do not run again for any individual user's export request.

## Why this line was drawn here

Re-importing every STEP file on every export request would materially increase export latency for a check whose main value (proving the exporter itself is correct) is already delivered once, robustly, by the test suite. This mirrors the same reasoning Sprint 6 used for preview-generation coupling (see [`08-alchemist/173-partial-compilation-policy.md`](../08-alchemist/173-partial-compilation-policy.md)): a check worth running once per code change is not automatically worth running once per request.
