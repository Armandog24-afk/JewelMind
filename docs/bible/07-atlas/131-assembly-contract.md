# Assembly Contract

The normative `AtlasAssembly` model is `specs/atlas/v1/geometry-assembly.schema.json`; a real worked example (`solitaire-assembly.json`, generated from the default definition) is in `specs/atlas/v1/examples/`.

## Current `SolitaireAssembly`

| Field | Current value/mapping |
|---|---|
| `assemblyId` | `"solitaire"` (the only assembly type; implicit, not a literal string constant anywhere in code) |
| `requiredComponents` | `["band", "stone_reference", "prongs", "basket_support"]` — all four, always |
| `optionalComponents` | none |
| `components` | `GeneratedModel.components` (a `dict[str, GeneratedComponent]`) |
| `assemblyMetadata` | `GeneratedModel.definition_hash`, `.generator_version`, `.generation_duration_s` |
| `transformOwnership` | **Not implemented** — see [`125-transformations.md`](125-transformations.md); each component computes its own absolute placement, no parent-owned transform exists |
| `aggregateBoundingBox` | `GeneratedModel.bounding_box` (union of `combined_metal`'s bbox and `stone_reference`'s bbox) |
| `totalProductionMetalVolume` | `GeneratedModel.combined_metal_volume_mm3` |
| `componentCount` | `len(GeneratedModel.components)` = 4, always, for the current assembly |
| `generationStatus` | Not an explicit field — derivable from `warnings` |

## Required vs. optional components

**All four current components are required; none is optional.** `build_solitaire_ring()` always calls all four `build_*` functions unconditionally — there is no code path that skips a component based on the definition's field values (contrast: `JM-MANUFACTURING-001` conditionally *warns*, but never conditionally *omits* a component).

## Child identity

Each component's identity within the assembly is its `name` string key in the `components` dict (`"band"`, `"stone_reference"`, `"prongs"`, `"basket_support"`) — see [`138-component-naming-and-identity.md`](138-component-naming-and-identity.md) for the full identity discussion, including the sub-identity question for individual prongs within the `prongs` compound.

## Real example: the default solitaire

From `specs/atlas/v1/examples/solitaire-assembly.json` (generated by running `build_solitaire_ring(default_definition())`): `componentCount: 4`, `totalProductionMetalVolume: 341.44334316909976` mm³, `aggregateBoundingBox` spanning `x: [-10.7, 10.7]`, `y: [-3.635, 3.635]`, `z: [-10.7, 15.6]`, `generationStatus: SUCCEEDED`, zero warnings.
