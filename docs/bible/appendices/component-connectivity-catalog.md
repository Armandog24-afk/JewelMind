# Appendix: Component Connectivity Catalog

Real connectivity facts for the default six-prong solitaire, generated by `jewelmind.geometry.inspection.build_connectivity_graph()` — see [`470-component-connectivity-model.md`](../16-geometry-inspection/470-component-connectivity-model.md).

## Per-component internal connectivity

| Component | Internally one connected solid? |
|---|---|
| `band` | Yes — 1 solid |
| `stone_reference` | Yes — 1 solid |
| `basket_support` | Yes — 1 solid |
| `prongs` | No — a compound of 6 (or 4) independent solids by design; the compound itself is not internally connected, each prong solid is separate |

## Production connectivity graph (`graphType: PRODUCTION`)

Nodes: `band`, `prongs`, `basket_support` (StoneReference deliberately excluded).

| Edge | Connected? | Basis |
|---|---|---|
| band ↔ prongs | Yes | DISTANCE (0.0mm) |
| band ↔ basket_support | Yes | DISTANCE (0.0mm) |
| prongs ↔ basket_support | Yes | DISTANCE (0.0mm) |

Real result: **1 connected group** — `["band", "basket_support", "prongs"]`. `isFullyConnected: true`, `disconnectedGroupCount: 0`.

## Full assembly connectivity graph (`graphType: FULL_ASSEMBLY`)

Nodes: all 4 components, including `stone_reference`.

| Edge | Connected? | Basis |
|---|---|---|
| band ↔ stone_reference | **No** | DISTANCE (0.9mm — the one genuinely separated pair) |
| stone_reference ↔ prongs | Yes | DISTANCE (0.0mm) |
| stone_reference ↔ basket_support | Yes | DISTANCE (0.0mm) |
| (production pairs above) | Yes | DISTANCE |

Real result: **1 connected group** of all 4 — stone_reference reaches the group via prongs/basket_support even though it doesn't touch band directly. `isFullyConnected: true`.

## Deliberately-broken test fixture (never a real jewelry model)

Two plain cubes placed 100mm apart, inspected by `backend/tests/test_geometry_inspection.py::TestDisconnectedFixture`: real result **2 disconnected groups**, `isFullyConnected: false`, `disconnectedGroupCount: 1` — proving the pipeline correctly detects and reports genuine disconnection rather than assuming connectivity.
