# Appendix: Atlas Inspection Catalog

Every geometric fact Atlas can currently produce, from `specs/atlas/v1/test-vectors/inspection-vectors.json`, generated by running the real implementation.

| Check | `checkType` | Component | Runtime or test-only |
|---|---|---|---|
| Fuse yields ≥1 solid | `SOLID_COUNT` | `combined_metal` | **Runtime** |
| Shape exists | `SHAPE_EXISTS` | band, stone_reference, prongs, basket_support | Test-only |
| Positive volume | `VOLUME` | Same four | Test-only |
| Plausible bounding box | `BOUNDING_BOX` | band, assembly | Test-only |
| Component count = 4 | `COMPONENT_COUNT` | solitaire | Test-only |
| Generated prong count matches requested | `COMPONENT_COUNT` | prongs | Test-only |
| Stone-metal Z separation | `CONNECTIVITY` | stone_reference | Test-only |
| Topology validity | `TOPOLOGY_VALIDITY` | any | **Does not exist — status UNKNOWN** |
| Stone-metal intersection (true geometric intersection, not bbox) | `INTERSECTION` | stone_reference / combined_metal | **Does not exist — status NOT_APPLICABLE** |

## Summary

**Runtime geometry inspections currently implemented: 1** (the fuse solid-count check backing `FORGE-GEOM-001`). **Inspections existing only in tests: 7** (shape exists, positive volume ×4 components collapsed to 1 category, bbox plausibility, component count, prong count match, stone separation — see the full per-component breakdown in `backend/tests/test_geometry.py`). **Inspections that do not exist in any form: topology validity, general intersection analysis, connectivity beyond the single fuse check, local-thickness analysis.**
