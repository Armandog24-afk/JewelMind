| Golden ID | Real JDL variation |
|---|---|
| `SOL-001-default-solitaire` | None — the canonical schema default. Also stands in for "6-prong comfort-fit" from the brief's selection list, since that combination is the default and would be a geometrically identical, redundant case. |

| `SOL-004-four-prong-flat` | `setting.prongCount: 4`, `band.profile: "flat"` |

## Fast vs. full suite

Per `goldens/solitaire-v1/manifest.json`:

- **Fast suite** (3 cases): `SOL-001-default-solitaire`, `SOL-002-four-prong-comfort-fit`, `SOL-003-six-prong-flat`.
- **Full suite** (all 9): every case above.

Both currently run in the same `backend/tests/test_geometry_quality_*.py` pytest pass — no separate CI job splits them yet, since 9 cases are not currently expensive enough to require it. See [`512-ci-regression-gating.md`](../17-geometry-quality/512-ci-regression-gating.md).
