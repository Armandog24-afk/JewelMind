## Notes grounded in the real code

- `NO_ARBITRARY_NUMERIC_MAPPING` is the file's own docstring-flagged "mandatory category" (referencing `docs/bible/13-design-intent/318` and "39 of the Sprint 11 brief") — every case in it asserts `no_numeric_field_changed()`, i.e. `not any(d.changed for d in proposal.diff)`, proving the request's `DesignerProposal.diff` shows zero technical JDL change even though a real aesthetic statement or unresolved descriptor was extracted.
- `unknown-01`/`unknown-02` deliberately submit an out-of-vocabulary target (`"halo"`) and concept (`"MOOD"`) respectively to prove the pipeline preserves them as unresolved text rather than crashing or guessing a classification.
- `unresolved-03` and `unresolved-04` are mixed cases: each request produces both a real resolved `IntentStatement` and a separate preserved unresolved descriptor in the same response, checked with `all_of(...)`.
- All 88 cases run through the real `DesignerService.interpret()` pipeline via `FakeDesignerProvider(response=case.raw)` — i.e. this corpus exercises the same code path (`designer/service.py` -> `design_intent/resolver.py`) that a live Anthropic-backed request would use, only with the provider's structured output supplied directly instead of generated by a model call.
