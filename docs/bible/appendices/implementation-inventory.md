# Appendix: Implementation Inventory

Generated by inspecting the actual modules in `backend/jewelmind/`,
`frontend/src/`, and `shared/`.

| Module | Responsibility | Maturity | Public interface | Dependencies | Limitations |
|---|---|---|---|---|---|
| `domain/schema.py` | Canonical `JewelryDefinition` and nested models. | Mature — hardened for strict types, finite numbers, locked schema version. | `JewelryDefinition`, `ProjectInfo`, `RingSpec`, etc. | Pydantic v2. | Hand-mirrored to TypeScript; no codegen. |
| `domain/defaults.py` | The default definition. | Mature. | `default_definition()` | `domain/schema.py`. | None known. |
| `domain/disclaimer.py` | Canonical disclaimer text. | Mature. | `PROFESSIONAL_REVIEW_NOTICE` | None. | Must be kept identical to `shared/disclaimer.ts` by hand. |
| `validation/engine.py` | Runs the sixteen business rules. | Mature — 20 dedicated tests. | `validate_definition()`, `has_errors()` | `validation/rules.py`, `validation/sizing.py`. | Mirrored by hand in `shared/validation/engine.ts`. |
| `validation/sizing.py` | EU/French size ↔ diameter conversion. | Mature. | `eu_size_to_inner_diameter()`, `inner_diameter_to_eu_size()`, `sizing_consistency()` | None. | EU/French convention only, not German. |
| `geometry/constants.py` | Coordinate convention constants. | Mature. | `inner_radius()`, `outer_radius()`, `band_top_z()`, `prong_center_radius()`, `EMBED_MM` | None. | None known. |
| `geometry/model.py` | Result types for geometry builders. | Mature. | `BoundingBox`, `GeneratedComponent`, `GeneratedModel` | CadQuery. | None known. |
| `geometry/components/band.py` | Band builder (flat/comfort-fit). | Mature — 4 dedicated tests. | `build_ring_band()` | CadQuery, `geometry/constants.py`, `geometry/primitives/selectors.py`. | Outer-rim fillet has a documented fallback path. |
| `geometry/components/stone.py` | Stone reference builder. | Mature — deliberately simplified. | `build_stone_reference()` | CadQuery, `geometry/constants.py`. | Not a gemological reproduction; round only. |
| `geometry/components/prongs.py` | Prong builder. | Mature. | `build_prongs()` | CadQuery, `geometry/constants.py`. | Plain cylinders, 4 or 6 count only. |
| `geometry/components/basket.py` | Basket support builder. | Mature — deliberately simple. | `build_basket_support()` | CadQuery, `geometry/constants.py`. | Plain cylindrical shell, not decorative. |
| `geometry/assemblies/solitaire.py` | Combines all four components. | Mature — 6 dedicated tests covering the full assembly. | `build_solitaire_ring()` | All `geometry/components/*`. | Falls back to a multi-solid compound if boolean fuse fails (by design, LAW-005). |
| `preview/mesh.py` | Tessellates components to STL + manifest. | Mature. | `write_component_previews()` | `geometry/model.py`. | Per-component STL, not a single packaged GLB (ADR-007). |
| `exporters/filenames.py` | Filename sanitization. | Mature. | `sanitize_filename()` | None. | None known. |
| `exporters/step_exporter.py` | Real STEP export. | Mature. | `export_step()` | CadQuery. | Excludes stone by default. |
| `exporters/stl_exporter.py` | Real STL export. | Mature. | `export_stl()` | CadQuery. | Excludes stone by default. |
| `exporters/json_exporter.py` | Canonical JSON export. | Mature. | `export_json()` | `domain/schema.py`. | None known. |
| `exporters/specification.py` | Markdown specification. | Mature — timestamp bug fixed in the hardening pass. | `build_specification()` | `domain/disclaimer.py`, `geometry/model.py`, `validation/rules.py`. | Markdown only, no PDF. |
| `services/model_service.py` | Orchestration, cache, temp-file lifecycle. | Mature — hardened for unique temp files and cleanup. | `model_service` (singleton), `ModelService`, `ModelRecord` | All of the above. | In-memory cache, capped at 20 entries, cleared on restart. |
| `services/cad_engine.py` | One-time CAD engine readiness probe. | Mature — added in the hardening pass. | `probe_cad_engine()`, `cad_engine_ready()`, `cad_engine_error()` | CadQuery. | Probes once at import time; does not re-check mid-process (by design — see ADR discussion in `004-jewelmind-constitution.md` context). |
| `api/app.py` | FastAPI app factory. | Mature — hardened for safe error-detail serialization. | `create_app()`, `app` | FastAPI, `api/errors.py`, `api/routes.py`. | None known. |
| `api/routes.py` | All HTTP routes. | Mature — hardened for lazy CAD import and error-code mapping. | Nine routes (see `appendices/api-inventory.md`). | `services/model_service.py` (lazily), `services/cad_engine.py`, `validation/engine.py`. | None known. |
| `api/schemas.py` | Request/response models. | Mature — hardened for strict types and tolerance validation. | `HealthResponse`, `GenerateResponse`, `ExportStlRequest`, etc. | Pydantic v2, `validation/rules.py`. | None known. |
| `api/errors.py` | Error type hierarchy. | Mature. | `AppError` and its subclasses. | None. | None known. |
| `utils/hashing.py` | Canonical serialization + hashing. | Mature. | `canonical_json()`, `definition_hash()` | `domain/schema.py`. | None known. |
| `utils/logging.py` | Structured logging config. | Mature. | `configure_logging()`, `get_logger()` | `structlog`. | None known. |
| `frontend/src/store/useProjectStore.ts` | The single Zustand store. | Mature. | `useProjectStore` and its actions. | Zustand, `api/client.ts`, `store/persistence.ts`. | None known. |
| `frontend/src/store/persistence.ts` | `localStorage` load/save/clear. | Mature — hardened with structural validation. | `loadDefinition()`, `saveDefinition()`, `clearDefinition()` | `shared/types/jewelry-definition.ts::isValidJewelryDefinition`. | Single project slot. |
| `frontend/src/hooks/useComponentGeometries.ts` | Fetches/parses/disposes preview meshes. | Mature — hardened for abort/dispose/keep-last-good. | `useComponentGeometries()` | `three`'s `STLLoader`, `api/client.ts`. | None known. |
| `shared/types/jewelry-definition.ts` | TypeScript schema mirror + runtime guard. | Mature. | `JewelryDefinition`, `createDefaultDefinition()`, `isValidJewelryDefinition()` | None. | Hand-mirrored from the Python schema. |
| `shared/validation/engine.ts` | Frontend validation mirror. | Mature. | `validateDefinition()`, `hasErrors()` | `shared/validation/rules.ts`, `sizing.ts`. | Hand-mirrored from the Python engine. |
