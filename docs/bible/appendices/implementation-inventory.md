# Appendix: Implementation Inventory

Generated by inspecting the actual modules in `backend/jewelmind/`,
`frontend/src/`, and `shared/`.

| Module | Responsibility | Maturity | Public interface | Dependencies | Limitations |
|---|---|---|---|---|---|
| `domain/schema.py` | Canonical `JewelryDefinition` and nested models. | Mature — hardened for strict types, finite numbers, locked schema version. | `JewelryDefinition`, `ProjectInfo`, `RingSpec`, etc. | Pydantic v2. | Hand-mirrored to TypeScript; no codegen. |
| `domain/defaults.py` | The default definition. | Mature. | `default_definition()` | `domain/schema.py`. | None known. |
| `domain/disclaimer.py` | Canonical disclaimer text. | Mature. | `PROFESSIONAL_REVIEW_NOTICE` | None. | Must be kept identical to `shared/disclaimer.ts` by hand. |
| `validation/engine.py` | Runs the sixteen business rules. | Mature — 20 dedicated tests. | `validate_definition()`, `has_errors()` | `validation/rules.py`, `validation/sizing.py`. | Mirrored by hand in `shared/validation/engine.ts`. |
| `validation/sizing.py` | EU/French size ↔ diameter conversion. | Mature. | `eu_size_to_inner_diameter()`, `inner_diameter_to_eu_size()`, `sizing_consistency()` | None. | EU/French convention only, not German. |
| `geometry/constants.py` | Coordinate convention constants. | Mature. | `inner_radius()`, `outer_radius()`, `band_top_z()`, `prong_center_radius()`, `EMBED_MM` | None. | None known. |
| `geometry/model.py` | Result types for geometry builders. | Mature. | `BoundingBox`, `GeneratedComponent`, `GeneratedModel` | CadQuery. | None known. |
| `geometry/components/band.py` | Thin re-export of `geometry/shank/build_shank()` (Sprint 17). | Mature. | `build_ring_band()` | `geometry/shank/`. | See `geometry/shank/` rows below. |
| `geometry/shank/profile.py` | Section-profile builder (flat/comfort-fit), shared by uniform and tapered paths. | Mature — Sprint 17. | `build_profile()`, `flat_profile_wire()`, `comfort_fit_profile_wire()` | CadQuery. | Knife-edge profile PLANNED, not implemented. |
| `geometry/shank/taper.py` | Deterministic head-anchored taper interpolation. | Mature — Sprint 17. | `taper_ratio()`, `angle_deg_for_u()` | `domain/schema.py::BandTaperSpec`. | Only `TOWARD_BOTTOM`, linear; `TOWARD_HEAD` PLANNED. |
| `geometry/shank/builder.py` | Dispatches uniform revolve vs 48-section tapered loft. | Mature — Sprint 17, 77 dedicated tests. | `build_shank()` | CadQuery, `geometry/connection.py`, `geometry/shank/{profile,taper}.py`. | Tapered path has no outer-rim fillet (documented v1 limitation). |
| `geometry/shank/capability.py` | CURRENT vs PLANNED Shank capability registry. | Mature — Sprint 17. | `SHANK_CAPABILITIES`, `get_shank_capability()` | None. | Mirrored at `specs/shank/v1/capability-registry.json`. |
| `geometry/connection.py` | Explicit Shank → RingHead connection interface. | Mature — Sprint 17. | `ShankConnectionInterface`, `shank_connection_interface()` | `geometry/constants.py`. | None known. |
| `geometry/components/stone.py` | Thin re-export of `geometry/stone/build_stone()` (Sprint 18). | Mature. | `build_stone_reference()` | `geometry/stone/`. | See `geometry/stone/` rows below. |
| `geometry/stone/outline.py` | 7 pure 2D outline primitives → closed `cq.Wire`. | Mature — Sprint 18. | `round_outline()`, `oval_outline()`, `marquise_outline()`, `pear_outline()`, `emerald_outline()`, `princess_outline()`, `cushion_outline()` | CadQuery. | Software reference outlines, not commercial cuts. Pear is a simplified non-tangent silhouette. |
| `geometry/stone/builder.py` | Dispatches round (byte-identical pre-Sprint-18 path) vs a shared 3-level loft for 6 shapes; applies orientation. | Mature — Sprint 18, 92 dedicated tests. | `build_stone()` | CadQuery, `geometry/constants.py`, `domain/stone_dimensions.py`, `geometry/stone/{outline,errors}.py`. | No faceting; `isGemologicalReproduction` always `false`. |
| `geometry/stone/capability.py` | CURRENT vs PLANNED shape registry; setting-compatibility axis. | Mature — Sprint 18. | `STONE_SHAPE_CAPABILITIES`, `get_stone_shape_capability()` | `domain/schema.py`. | Mirrored at `specs/stone/v1/shape-registry.json`. |
| `geometry/stone/errors.py` | Structured Stone System errors. | Mature — Sprint 18. | `StoneShapeUnsupportedError`, `StoneGenerationError` | None. | None known. |
| `geometry/stone/__init__.py` | Deliberately **non-eager** — imports nothing. | Mature — Sprint 18. | — | None. | Prevents a real circular import; see the file's own docstring. |
| `domain/stone_dimensions.py` | The single LENGTH/WIDTH/DEPTH resolution point, consumed by both Atlas and Forge. | Mature — Sprint 18. | `resolved_length_mm()`, `resolved_width_mm()`, `resolved_depth_mm()` | `domain/schema.py`. | In `domain/` so neither Atlas nor Forge gains a new dependency on the other. |
| `geometry/components/prongs.py` | Prong builder. | Mature. | `build_prongs()` | CadQuery, `geometry/connection.py` (Sprint 17). | Plain cylinders, 4 or 6 count only. |
| `geometry/components/basket.py` | Basket support builder. | Mature — deliberately simple. | `build_basket_support()` | CadQuery, `geometry/connection.py` (Sprint 17). | Plain cylindrical shell, not decorative. |
| `geometry/assemblies/solitaire.py` | Combines all four components. | Mature — 6 dedicated tests covering the full assembly. | `build_solitaire_ring()` | All `geometry/components/*`. | Falls back to a multi-solid compound if boolean fuse fails (by design, LAW-005). |
| `preview/mesh.py` | Tessellates components to STL + manifest. | Mature. | `write_component_previews()` | `geometry/model.py`. | Per-component STL, not a single packaged GLB (ADR-007). |
| `exporters/filenames.py` | Filename sanitization. | Mature. | `sanitize_filename()` | None. | None known. |

| `exporters/specification.py` | Markdown specification. | Mature — timestamp bug fixed in the hardening pass. | `build_specification()` | `domain/disclaimer.py`, `geometry/model.py`, `validation/rules.py`. | Markdown only, no PDF. |
| `services/model_service.py` | Orchestration, cache, temp-file lifecycle. | Mature — hardened for unique temp files and cleanup. | `model_service` (singleton), `ModelService`, `ModelRecord` | All of the above. | In-memory cache, capped at 20 entries, cleared on restart. |
| `services/cad_engine.py` | One-time CAD engine readiness probe. | Mature — added in the hardening pass. | `probe_cad_engine()`, `cad_engine_ready()`, `cad_engine_error()` | CadQuery. | Probes once at import time; does not re-check mid-process (by design — see ADR discussion in `004-jewelmind-constitution.md` context). |
| `api/app.py` | FastAPI app factory. | Mature — hardened for safe error-detail serialization. | `create_app()`, `app` | FastAPI, `api/errors.py`, `api/routes.py`. | None known. |
| `api/routes.py` | All HTTP routes. | Mature — hardened for lazy CAD import and error-code mapping. | Nine routes (see `appendices/api-inventory.md`). | `services/model_service.py` (lazily), `services/cad_engine.py`, `validation/engine.py`. | None known. |
