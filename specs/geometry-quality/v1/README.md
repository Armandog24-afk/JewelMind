# Geometry Quality v1 — machine-readable specifications

The machine-readable half of [`docs/bible/17-geometry-quality/`](../../../docs/bible/17-geometry-quality/README.md). A Golden Model is a **software regression reference**, never a professional or manufacturing approval (QUALITY-GOV-001).

## Schemas

| File | Describes |
|---|---|
| `version-fingerprint.schema.json` | Real version identifiers relevant to geometry regression. |
| `geometry-snapshot.schema.json` | Stable, normalized geometric facts for one golden case. |
| `golden-model.schema.json` | A full Golden Model: design reference + snapshot + fingerprint + artifact expectations. |
| `geometry-diff.schema.json` | A structured comparison between an expected and an actual snapshot. |
| `quality-result.schema.json` | The outcome of verifying one golden against real regenerated geometry. |
| `golden-suite.schema.json` | The manifest for one Golden Suite (`goldens/<suiteId>/manifest.json`). |

## Test vectors

Every file under `test-vectors/` is generated by `backend/generate_quality_test_vectors.py` (run once, then deleted — see `backend/tests/test_geometry_quality_schemas.py`, which re-derives equivalent vectors live) running the real `compare_snapshot()`/`generate_candidate_baseline()` against the real accepted `SOL-001-default-solitaire` golden. Nothing here is hand-invented.

| File | Demonstrates |
|---|---|
| `exact-invariant-vectors.json` | An EXACT_INVARIANT change (component count, StoneReference role, a missing component) is detected. |
| `numeric-diff-vectors.json` | A NUMERIC_REGRESSION comparison: ULP-level noise passes, a 5% volume change fails. |
| `relationship-diff-vectors.json` | A RELATIONSHIP_REGRESSION comparison: flipped connectivity/intersection facts are detected. |
| `version-mismatch-vectors.json` | The same topology change is `REGRESSION` when the kernel version is unchanged, and `VERSION_REVIEW_REQUIRED` when it differs (QUALITY-GOV-010). |
| `baseline-update-vectors.json` | A freshly generated candidate baseline next to its accepted-state shape — acceptance is always an explicit, separate transition (QUALITY-GOV-003/004). |

## Golden fixtures

The real Golden Suite lives under [`goldens/solitaire-v1/`](../../../goldens/solitaire-v1/) at the repository root, not under `specs/` — each case is a real, generated `design.json` (the source JDL) plus `snapshot.json` (the accepted `GoldenModel`, geometry snapshot embedded). No STEP/STL binaries are committed; artifact regression is re-derived at test time from the real exporters (QUALITY-GOV-007/008).
