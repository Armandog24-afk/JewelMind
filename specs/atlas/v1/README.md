# Atlas Geometry Core v1 — Machine-Readable Specification

The machine-readable half of Atlas. The narrative, architecture, and contract half lives in [`docs/bible/07-atlas/`](../../../docs/bible/07-atlas/README.md); start there for context.

## What Atlas is

Atlas is the deterministic geometry layer: the formal model of the geometric primitives, coordinate conventions, component/assembly contracts, construction pipeline, and inspection framework already implemented in `backend/jewelmind/geometry/`. **Atlas v1 is a specification and classification layer over the existing CadQuery/OpenCascade geometry code — it does not replace CadQuery, does not add a new kernel, and does not change any generated geometry.**

## Files

| File | Purpose |
|---|---|
| [`geometry-component.schema.json`](geometry-component.schema.json) | Structural schema for one `AtlasGeometryComponent` record |
| [`geometry-assembly.schema.json`](geometry-assembly.schema.json) | Structural schema for one `AtlasAssembly` record |
| [`geometry-metadata.schema.json`](geometry-metadata.schema.json) | Structural schema for generation-level metadata |
| [`geometry-inspection-result.schema.json`](geometry-inspection-result.schema.json) | Structural schema for one geometric-fact inspection result |
| [`geometry-error.schema.json`](geometry-error.schema.json) | Structural schema for a conceptual `AtlasGeometryError` |
| [`component-manifest.schema.json`](component-manifest.schema.json) | Structural schema for one component-manifest record |
| [`examples/`](examples/) | 5 real component/assembly records, generated by running `build_solitaire_ring(default_definition())` directly |
| [`test-vectors/`](test-vectors/) | Coordinate, transform, metadata, inspection, and component-manifest vectors, all generated from a live run — never invented |

## No fabricated measurements

Every numeric value in `examples/` and `test-vectors/` was produced by calling the real backend directly during this Sprint (`backend/jewelmind/geometry/assemblies/solitaire.py::build_solitaire_ring`, `backend/jewelmind/preview/mesh.py::write_component_previews`, `backend/jewelmind/geometry/constants.py`) against `default_definition()`. None is estimated or invented.

## How these files are validated

`backend/tests/test_atlas_registry.py` (added in Sprint 5) validates all 6 schemas, validates all 5 examples against their respective schemas, and cross-checks the volume/bounding-box/metadata test vectors against a fresh live run of the real geometry builders.
